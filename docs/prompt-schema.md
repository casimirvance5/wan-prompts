# wan-3 prompt schema

1. **Output** — duration, ratio, resolution, and intended delivery.
2. **Subject** — identity, materials, and count.
3. **Timeline** — ordered actions with a clear beginning and end.
4. **Camera** — framing, lens feel, motion, and focus.
5. **Look and sound** — lighting, palette, ambience, speech, or music.
6. **Hard constraints** — unwanted text, extra limbs, abrupt cuts, and continuity rules.

Pass the reviewed prompt to the Argolink model page's documented request fields.
